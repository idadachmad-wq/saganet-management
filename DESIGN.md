# SaGa-Net Workspace — Style Reference
> green-first ISP operations workspace

**Theme:** light + dark · **Brand:** hijau perusahaan

Identitas visual SaGa-Net berpusat pada hijau (`#16a34a` / emerald) dengan aksen teal. Kanvas mint lembut, border hijau muda, CTA gradient hijau→teal, dan surface yang bertint hijau — bukan netral abu/biru. Dark mode memakai forest black dengan highlight lime/emerald.

## Tokens — Colors

| Name | Value | Role |
|------|-------|------|
| Mint Canvas | `#f0fdf6` | Background halaman (light) |
| Forest Night | `#04140c` | Background halaman (dark) |
| Brand Green | `#16a34a` | Brand primer, CTA, nav aktif, KPI stripe |
| Brand Soft | `#bbf7d0` | Tint panel, badge, fokus input |
| Brand Strong | `#15803d` | Teks aksen brand di light |
| Lime Glow | `#4ade80` | Brand di dark mode |
| Teal Accent | `#0d9488` | Aksen sekunder, chart keluar, gradient CTA |
| Ink Forest | `#052e16` | Teks utama (light) |
| Mint Text | `#ecfdf3` | Teks utama (dark) |

## Applied

- Banner hero login & dashboard: gradient brand hijau
- Nav aktif / tab aktif: fill hijau solid + shadow hijau
- Panel: tint hijau lembut + border mint
- Chart: hijau (masuk) + teal (keluar)
- Logo mark `SG`: kotak gradient brand
